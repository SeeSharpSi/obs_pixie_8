# Video
* For personal in-home use 
	* Not for commercial space 
* No more than 10 participants or so 
	* Kinda scaleable 

## Qs 
* Will the role have any role in the games being played? (e.g. Monopoly bank) 
	* No 
	* The only thing it does is set up for the game night and clean up 
	* The only active part during game night will be monitoring snacks 
	* Offer user list of sweet, salty snacks and drinks 
	* Allow user to select space for where snacks are served 
	* Maybe collect how many people are attending first 
* Will all games be available or will people bring their own? 
	* Restrict this to what user has in their home 
	* You must allow user to set up for board games and video games (and maybe card games, not required) 
* What kind of equipment to include? 
	* Equipment should be its own feature 
	* Might already have TV and screen to use. Think about console (xbox, ps, etc.) 
	* Controllers, types of controllers, etc. 
* Should we include regular chairs, gaming, etc? 
	* Equipment set up is different than room setup 
	* Set up space for gaming area; you show user a floor plan 
	* "Here's your area" -> allow user to pick where game is set up -> allow users to move, remove, or add furniture 
	* Separate from the equipment setup 
	* Don't have to make own floor plan - google one and use it 
* Are we taking allergies into account? 
	* You're gunna serve what you're gunna serve 
	* Pay attention to allergies - could be included in guest list 
	* Handle this in your interface 
	* Prefer to tend to allergies in guest list 
* Are the greetings customizable? 
	* Yes. Should be able to input how you want your guests greeted
	* Don't need specific greeting for each guest 
	* Be like "hey {name}, are you playing video games tonight?" 
	* Could give user a canned set of greetings to select from 
* Should it be expected to serve snacks? 
	* No, it sets them up buffet style 
	* It monitors them; check "every 30min" and refill as needed 
* When preparing gaming area what specific tasks is it expected to do? 
	* Not worried about cleaning space beforehand 
	* Include option to clean up after the game night is done 
	* In addition to greeting, the robot should be able to collect coats, umbrellas, guide guests to play area, where to guide?, etc. 
* For cleanup after the game night is it just a cleanup button? 
	* Have a little more. Maybe think about what I'd have to do (pick up trash, restore room to original furniture config, etc.) 
* What is the biggest issue you run into yourself when setting up? 
	* House cleaning, setup, whatever 
* How do you choose which game to play at game night? 
	* Offer user list of games to choose from 
	* 4-5 board games 
	* 4-5 video games 
	* Pick what you would have in your own home 
	* This should branch; are you playing board games, video games, both? Robot will do different things depending 
	* Game selection should live in equipment setup (31:00) 
* Should snacks beverages be customizable to users? 
	* We answered for allergies 
	* Use prepackaged snacks - it's not like the robot bakes a cake 
	* The robot shouldn't server snacks, it just sets up snacks 
	* Address quantities (e.g. 3 bags of chips, 1 2-liter, etc.) 
	* No more than about 10 guests 
* What are the setup rules for the games? 
	* Assume the robot knows how to set up the games 
* What do you want the robot to do with board games? 
	* Could have checkbox that says "set up monopoly first" or something 
* Can the user add more games than what are on there? 
	* Could add this, but not required 
* Do you have a particular set of snacks that you want? 
	* Just think about "what would I serve?" 
	* Make it realistic 
* Can the robot suggest games based on guest's age? 
	* It could, but if you're inviting guests over you're probably setting up games for that age-bracket anyways 
* Should the project ask about preferences for snacks and seats? 
	* Could allow defining where each game is set up (Monopoly here, Mario Kart here) 
	* No settings for the robot - no docking information, etc. 
	* Assume normal flow, no snags, etc. 
* Dietary restrictions? 
	* If you have a guest with peanut allergies, grey out something that contains peanuts 
* Are the functions strict step-by-step? 
	* The prepare game area function might be "come in here, clean out trash, move two tables out, add four chairs, etc." 
	* Equipment may be "turn on computers, install software, open up monitors, select game consoles, etc." 
	* Equipment is equipment, game area is the room space 
* Order of functions? 
	* It's fine to have order of operations, but don't enforce linearity 
	* Testing shouldn't be a nightmare 
* Can you use presets? 
	* Could use presets but isn't required and shouldn't be driven by presets 
* Can you have alcohol as a drink? 
	* Yeah but not needed 
* What types of equipment do you want? 
	* Could include environment, lighting, temperature, etc. 
* When guiding/greeting guests, should it be in a designated area? 
	* Sure, like the front door or hallway
