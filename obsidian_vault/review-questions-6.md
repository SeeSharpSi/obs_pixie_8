# RQ 11-7
The view function allows the user to retrieve an artifact for the purpose of reading. Whereas the modify function retrieves an artifact for the purpose of making changes.
This difference exists for the purpose of storage read/write access. Several people viewing a file at the same time poses no problems, but several people modifying a file at the same time does. This means that users need to identify what they're doing so that system calls don't interfere with each other.
