This course required groups of students to create web-based accounting software.
This software was meant to meet the specification required by Dr. Mamo.
We had to create web-based software that would allow for populating a chart of accounts, journalizing transactions, preparing financial statements, and displaying computed ratios.
We also had to prepare documentation for the project. This includes a Software Testing Document, a User Manual, a Software Design Document, a class diagram, and a database diagram.
We started the course focused on an agile-based methodology, but two team members dropped the course, meaning we had to pivot. We landed on staying with agile, but focused our workload to better benefit our skillsets. 
To stay on track, we had bi-weekly meetings and frequent correspondence over direct messaging. 
Every sprint we would present to Dr. Mamo to acquire feedback on progress. We put our focus on the application over documentation, allowing us to quickly adapt to changes in our development plan. 
The application was created using Springboot, MariaDB, JavaScript, and HTML. Our database was hosted inside of a local container, while our Java runtime was managed with Maven.
